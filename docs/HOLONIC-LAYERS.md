# Holonic layers (lock)

Layers are **distinct**. Do not merge them in UI copy, APIs, or docs.

```
TRD StrataMesh
  └ Fog Node                    # productive capacity; NODE_WALLET treasury
      └ SO Metaverso            # one shared OS across nodes
          └ Domínio Virtual     # hypervisor / isolation of capacity
              └ Mundo Aberto    # persistent environment
                  └ Bancada CGU # isolated UGC sandbox (+ Panel ⊂ Bancada)
                      └ Utilizador | SCA
```

## Forbidden grouping

Do **not** label a single block “Anfitrião · SO e VM”. Host substrate, Metaverse OS, and Virtual Realm are separate.
