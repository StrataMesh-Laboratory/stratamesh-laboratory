# Research focus

Five centres of gravity. Expand applications only after these are measurable.

1. **DAG structure** — acyclicity, tip selection, parent delivery under loss  
2. **Identity** — node / agent / SCA identifiers without collapsing holonic layers  
3. **Resource proofs** — verifiable contribution against claimed Fog/Edge capacity  
4. **Service receipts** — evidence that work was requested, performed, settled  
5. **Settlement** — STRATA emission (`#mint` via PoC), circulation, burn (`#0`)

## Explicitly secondary (until 1–5 hold)

Metaverse OS chrome, Bancada product polish, DAO process theatre, marketing KYC flows.
