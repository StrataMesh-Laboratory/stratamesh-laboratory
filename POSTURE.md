# Laboratory posture

## One-line rule

**LAB** — experimental · may reset · not economically secure · not consensus-final in the production sense.

## Non-claims

| Claim | Lab position |
|-------|----------------|
| Mainnet | **No** |
| aBFT / Byzantine finality | **No** — lab finality only |
| Production post-quantum crypto | **No** — placeholders |
| Investment product | **No** |
| Fog Node is a retail account | **No** — treasury wallet only |
| Visitors have Panel/Bancada rights | **No** — PUBLIC clearance only |

## Economic poles (invariant language)

| Address | Role |
|---------|------|
| `#mint` | Emission source only (PoC); never receives; no spendable balance |
| Wallets | Circulation (nodes, users, SCAs) |
| `#0` | Burn sink; never transfers out |

Circulating supply excludes `#0`. Fog **NODE_WALLET** is distinct from user/SCA accounts.

## Communication

Public copy should describe positively what the lab **is**, without long “this is not X” lists — except where regulatory or safety clarity requires an explicit non-claim (custody, investment, mainnet).
